# Canvas Design & Visual Philosophy

## 🎯 Purpose
Guidelines for creating high-quality, museum-ready visual art (posters, designs, static pieces). Use when a user asks for "art," "poster," or "design."

## 🛠️ The Process / Fact

### 1. The Two-Step Workflow
1.  **Visual Philosophy (.md):** Create an aesthetic movement (e.g., "Brutalist Joy," "Geometric Silence"). Focus on form, space, and rhythm (4-6 paragraphs).
2.  **Visual Expression (.pdf/png):** Express the philosophy on a canvas. 90% visual, 10% minimal text.

### 2. Design Standards
- **Minimal Text:** Use text as a visual accent, never as long paragraphs.
- **Typography:** Use professional fonts (e.g., thin fonts, Swiss formalism). Access the `./canvas-fonts` directory for variety.
- **Craftsmanship:** Work must look painstakingly crafted (perfect spacing, no overlaps, clear margins).

## ⚠️ Known Quirks or Edge Cases
- **Overcrowding:** If the work isn't "perfect," refine and simplify rather than adding more graphics.
- **Boundaries:** All elements MUST stay within canvas boundaries.
